# Exemples de sorties

Exemple généré à partir de données fictives : aucune relation commerciale réelle.

Ces fichiers ont été produits par l'agent à partir du CRM fictif d'Orvane Solutions. Les noms d'entreprises sont réels pour que la veille web trouve de vraies actualités, mais les contacts, affaires, commandes et réclamations sont inventés.

- `briefs/` : fiches de visite (Markdown, HTML imprimable, texte audio)
- `dossiers/` : ce que l'agent a extrait du CRM avant de rédiger
- `comptes-rendus/` : compte rendu rédigé après une note vocale, puis sa version validée
